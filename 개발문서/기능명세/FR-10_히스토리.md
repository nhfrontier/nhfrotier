# FR-10 History v1.0

> **관련 문서**: [기능명세 인덱스](개발문서/기능명세/00_INDEX.md) | [PRD](개발문서/01_PRD.md) | [IA·화면](개발문서/03_IA_FUNCTION_SPEC.md) | [API/DB](개발문서/05_API_DB_SPEC.md)

## 1. 개요

사용자 행동, AI 작업, 댓글, 반영 결정, Version 생성을 시간순으로 기록한다. (PRD 9절)
History는 "왜 이렇게 됐는가"의 과정 기록이며, "지금 어떤 상태인가"를 담는 Version과 분리된 모델이다(기획안 6-1절).

## 2. 동작 상세

- 행위 주체를 `actor_type`(USER / AI / SYSTEM)으로 구분해 기록한다. 사용자 행동과 AI 작업을 모두 조회할 수 있다.
- 기록 대상: 프로젝트 변경, 파일 등록, AI 작업, 댓글, 반영 결정, Version 생성. Version 생성 이벤트는 History와 연결된다 → [FR-09](개발문서/기능명세/FR-09_버전관리.md)
- 이벤트는 `action_type / target_type / target_id / payload_summary`로 남긴다(05 6절 History 모델). 원문 전체가 아닌 요약을 저장한다.
- 권한 없는 사용자는 History를 조회할 수 없다(프로젝트 멤버십 검증).
- History(업무 과정 기록)와 감사 로그(운영·보안 기록)는 목적과 보존 정책이 다르다 → [FR-12](개발문서/기능명세/FR-12_감사추적.md)
