# FR-03 참고자료 v1.0

> **관련 문서**: [기능명세 인덱스](개발문서/기능명세/00_INDEX.md) | [PRD](개발문서/01_PRD.md) | [IA·화면](개발문서/03_IA_FUNCTION_SPEC.md) | [API/DB](개발문서/05_API_DB_SPEC.md)

## 1. 개요

파일 업로드, 목록, 삭제, 버전 연결, AI 참조 대상 선택을 지원한다. (PRD 9절)
내부 자료와 과거 산출물을 프로젝트 자산으로 축적해 AI 생성 맥락으로 재사용한다(기획안 1-1절).

## 2. 동작 상세

- 파일은 프로젝트와 연결되어 업로드·조회·삭제된다. 바이너리는 File Storage에, DB에는 메타데이터(경로·크기·mime)만 저장한다.
- 허용된 파일 형식과 크기 정책을 적용한다. 확장자·MIME·용량 검증과 확장자 위장 검사를 수행한다. (❓ 허용 형식·용량 상한 값 미결)
- AI 요청 시 사용자가 참조 여부를 **명시적으로 선택**한다. 선택하지 않은 자료는 AI에 전달되지 않는다(보안 결정).
- 파일 조회·삭제 시 프로젝트 멤버십을 검증한다(IDOR — 보안 규칙 [SECURITY.md](docs/guidelines/SECURITY.md)).
- 산출물과의 버전 연결은 `version_files`로 관리한다 → [FR-09](개발문서/기능명세/FR-09_버전관리.md) (구현 시기는 P4)
