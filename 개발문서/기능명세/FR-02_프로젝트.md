# FR-02 프로젝트 v1.0

> **관련 문서**: [기능명세 인덱스](개발문서/기능명세/00_INDEX.md) | [PRD](개발문서/01_PRD.md) | [IA·화면](개발문서/03_IA_FUNCTION_SPEC.md) | [API/DB](개발문서/05_API_DB_SPEC.md)

## 1. 개요

프로젝트명, 설명, 상태, 소유자, 멤버, 생성일, 최근 활동을 관리한다. (PRD 9절)
Canvas가 아니라 Project가 시작점이다 — 사람·자료·결과물·검토·Version·History를 한 단위로 묶는다(기획안 2-2절).

## 2. 동작 상세

- 프로젝트명/설명/소유자를 입력해 생성한다. 생성자는 소유자가 된다.
- 멤버를 초대하고 멤버별 권한을 구분한다. (권한 모델 ❓ 미결 — [FR-01](개발문서/기능명세/FR-01_인증권한.md) 참조)
- 프로젝트 상태 전이: `DRAFT → ACTIVE → REVIEW → COMPLETED → ARCHIVED` (03 상태 모델)
- 프로젝트의 모든 주요 변경(생성·수정·멤버 변경)은 History에 남는다 → [FR-10](개발문서/기능명세/FR-10_히스토리.md)
- 파일/의견/Version은 프로젝트 단위로 묶여 검색 가능해야 한다(03 UX 원칙).
