# FR-08 반영 결정 v1.0

> **관련 문서**: [기능명세 인덱스](개발문서/기능명세/00_INDEX.md) | [PRD](개발문서/01_PRD.md) | [IA·화면](개발문서/03_IA_FUNCTION_SPEC.md) | [API/DB](개발문서/05_API_DB_SPEC.md)

## 1. 개요

AI 제안은 자동 확정하지 않으며 담당자가 반영/보류/반려를 선택한다. (PRD 9절)
"AI가 제안하고, 사람이 최종 결정한다"는 이 제품의 설계 원칙을 실행하는 기능이다(기획안 3-3절).

## 2. 동작 상세

- AI가 취합한 각 의견([FR-07](개발문서/기능명세/FR-07_AI의견취합.md))에 대해 담당자가 **반영 / 보류 / 반려**를 선택한다.
- 결정 이유를 선택적으로 기록한다. 결정은 `review_items 1:1 review_decisions`로 남는다.
- 반영으로 선택된 의견을 기준으로 AI 수정 작업이 생성된다 → [FR-05](개발문서/기능명세/FR-05_AI제작.md) (source_type=AI_REVISION)
- 결정은 새 Version 생성의 근거가 되어, 어떤 의견이 어떤 결정을 거쳐 어느 버전에 반영됐는지 추적할 수 있다 → [FR-09](개발문서/기능명세/FR-09_버전관리.md)
- 관련 의견 상태가 함께 전이된다: `REVIEWED → ACCEPTED / REJECTED / DEFERRED` (03 상태 모델)
