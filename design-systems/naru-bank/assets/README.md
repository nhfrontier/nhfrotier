# assets/

**Empty by design.** No logo, icon set, illustration library, font binary or imagery was supplied with
this brief — see the Provenance section of `../readme.md`.

Nothing here was drawn, reconstructed or approximated from memory.

When real assets arrive, drop them in:

- `assets/logo.svg` — then update `guidelines/brand-wordmark.html` and `thumbnail.html` to use it
- `assets/icons/` — then repoint the `@import` in `tokens/icons.css`
- `assets/fonts/` — then repoint the `src` in `tokens/fonts.css`
- `assets/illustrations/` — then pass them into `Banner media` / `EmptyState media`
