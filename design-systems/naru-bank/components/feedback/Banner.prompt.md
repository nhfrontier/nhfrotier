Use `Banner` for merchandising strips between sections. Copy is a two-beat hook: muted question, then a bold payoff.

```jsx
<Banner tone="brand" eyebrow="중요한 일을 기다리고 있다면?" title="운세 확인하고 포인트도 받자☆" media={<img src="../assets/illustrations/..."/>}/>
```

Never stack two banners; put a section between them.
