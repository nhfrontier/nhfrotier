# 화면 리디자인 참고 캡처

`/proto` 대시보드(`mockup/app/proto/page.tsx`)를 비롯한 화면을 다시 그릴 때 보는 **외부 서비스 UI 캡처** 보관소다.
디자인 정본이 아니다. 정본은 `reference/doc-hub.html`이고, 여기 있는 것은 참고 자료일 뿐이다.

## 왜 이미지가 gitignore인가

저장소 루트 전체가 GitHub Pages로 공개 서빙된다 (`.github/workflows/pages.yml` — main은 `/`, dev는 `/dev/`).
캡처에는 브라우저 북마크 바의 사내 프로젝트명과 계정명이 함께 찍혀 있어 **공개 URL로 노출시킬 성격이 아니다.**
`design-systems/*/uploads/`·`mockup/public/assets/nh/`를 제외한 것과 같은 이유다.

그래서 이 폴더는 `.gitignore` 대상이고, **이 README.md만 추적된다.**
이미지는 각자 로컬에만 둔다. 파일이 없어도 저장소·빌드는 그대로 동작한다.

## 새 캡처를 추가할 때

1. 출처별 하위 폴더에 넣는다 (`genspark/`, `notion/` …).
2. 파일명은 `<출처>-<화면>.<확장자>` 형식으로 무엇인지 알아볼 수 있게 쓴다.
3. 위 표에 행을 추가한다. **무엇을 참고하려는지**를 적어야 나중에 쓸모가 있다.
